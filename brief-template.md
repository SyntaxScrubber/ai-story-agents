# Brief Template — fill in for each episode

- **Month / theme:** e.g. October — Halloween, cozy fantasy
- **Title idea:** (optional, the agent can suggest one)
- **Vibe:** e.g. cozy, witchy, magical, a little funny, not cruel
- **Length:** e.g. about 2 minutes, about 300-400 words of dialogue
- **Characters:** name, 1-line description each (2-4 characters max)
- **Setting:** e.g. a tiny home, a porch at dusk, a village market
- **Core conflict:** what goes wrong, in one sentence
- **Cliffhanger?** Yes / No — if yes, what question is left hanging?
- **What to avoid:** e.g. no real-world harm, no cheating/betrayal
  drama, no cruelty for its own sake
- **Tone note:** anything else the agent should know
